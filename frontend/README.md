# Insight Hive — frontend

Interface React (Vite + Tailwind) para login, clientes e upload de arquivos da análise multiagente.

## Desenvolvimento

```bash
npm install
npm run dev
```

Abre em [http://localhost:5173](http://localhost:5173). O backend FastAPI precisa estar em `http://localhost:8000`; o Vite faz proxy de `/api` para a API.

Usuário/senha padrão: `admin` / `admin`.
